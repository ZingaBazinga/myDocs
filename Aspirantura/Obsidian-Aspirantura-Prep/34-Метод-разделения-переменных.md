# Вопрос 34. Методы решения основных задач математической физики. Метод разделения переменных

← [[00-MOC-Aspirantura-Prep]] · Предыдущий: [[33-Задачи-Коши-Дирихле-Неймана]] · Программа: [[Вопросы программы вступительного экзамена в аспирантуру по специальности 1.2.2. Математическое моделирование, численные методы и комплексы программ#^q34]]

## Краткий ответ (для устного экзамена)

> [!abstract] Простыми словами — вся суть
> Основные **аналитические методы** решения задач матфизики:
> - **Метод разделения переменных (Фурье)** — ищем решение в виде произведения $u = X(x)T(t)$; УЧП распадается на два ОДУ.
> - **Метод Даламбера** — общее решение волнового уравнения: $u = F(x-ct) + G(x+ct)$.
> - **Метод характеристик** — решение вдоль характеристических кривых.
> - **Интегральные преобразования** — преобразование Фурье, Лапласа по пространственной переменной или времени.
> - **Функции Грина** — решение через интеграл от источника.
>
> **Метод разделения переменных** — основной метод для начально-краевых задач в областях простой геометрии. Схема:
> 1. Ищем $u(x,t) = X(x)T(t)$.
> 2. Подставляем в уравнение, делим на $XT$ → каждая часть зависит от своей переменной → обе равны константе $-\lambda$.
> 3. Получаем два ОДУ: пространственная задача Штурма-Лиувилля (собственные значения $\lambda_n$, собственные функции $X_n$) и временное уравнение.
> 4. Общее решение: $u = \sum_n C_n X_n(x) T_n(t)$.
> 5. Коэффициенты $C_n$ находим из начального условия через **ряды Фурье**.

## 1. Обзор методов решения задач матфизики

### Основные аналитические методы

**Формулировка (учебник):** для решения линейных задач математической физики применяются следующие методы.

| Метод | Когда применяется | Идея |
| --- | --- | --- |
| **Разделение переменных** | Ограниченная область, простые границы | $u = X(x)T(t)$ → два ОДУ |
| **Даламбера** | Волновое уравнение на прямой | $u = F(x-ct) + G(x+ct)$ |
| **Характеристик** | Гиперболические уравнения 1-го порядка | Решение вдоль характеристик |
| **Интегральные преобразования** | Неограниченная область | Фурье/Лаплас по $x$ или $t$ |
| **Функции Грина** | Эллиптические, параболические | Решение через точечный источник |
| **Потенциалов** | Эллиптические (Лаплас, Пуассон) | Представление через потенциалы |

> [!tip] Простыми словами
> Выбор метода определяется типом уравнения, геометрией области и условиями. Для ограниченной области с простыми границами — разделение переменных; для неограниченной — интегральные преобразования; для волны на прямой — Даламбер.

### Численные методы

**Формулировка (учебник):** для задач сложной геометрии или нелинейных уравнений применяются **численные методы**:
- конечно-разностные схемы ([[41-Основные-понятия-теории-разностных-схем-аппроксимация|Вопрос 41]]);
- метод конечных элементов;
- метод конечных объёмов.

## 2. Метод разделения переменных: общая схема

### Идея метода

**Формулировка (учебник):** для линейного УЧП в ограниченной области ищем решение в виде **произведения** функций, каждая из которых зависит только от одной переменной:
$$
u(x, t) = X(x)\,T(t).
$$
Подстановка в уравнение приводит к тому, что каждая часть зависит только от своей переменной. Поскольку переменные независимы, обе части равны одной и той же константе (параметру разделения $\lambda$).

> [!tip] Простыми словами
> «Разделяем» переменные: всё, что зависит от $x$, — в одну сторону, всё, что от $t$, — в другую. Обе части равны константе, иначе равенство не выполнялось бы для всех $x$ и $t$ одновременно.

### Общая схема для задачи с двумя переменными

Дано: линейное УЧП + граничные условия + начальное условие.

**Шаг 1.** Подставляем $u(x,t) = X(x)T(t)$ в уравнение и граничные условия.

**Шаг 2.** Разделяем переменные: делим уравнение на $X(x)T(t)$. Получаем:
$$
\frac{\text{часть, зависящая от } t}{\text{часть, зависящая от } t} = \frac{\text{часть, зависящая от } x}{\text{часть, зависящая от } x}.
$$
Левая часть зависит только от $t$, правая — только от $x$. Значит, обе равны константе $-\lambda$ (знак выбирается из соображений удобства).

**Шаг 3.** Получаем два ОДУ:
- **Пространственное уравнение** (задача Штурма-Лиувилля):
$$
L[X] + \lambda X = 0, \qquad \text{граничные условия на } X.
$$
- **Временное уравнение:**
$$
T' + \lambda \alpha T = 0 \quad \text{или} \quad T'' + \lambda c^2 T = 0.
$$

**Шаг 4.** Решаем задачу Штурма-Лиувилля: находим **собственные значения** $\lambda_n$ и **собственные функции** $X_n(x)$.

**Шаг 5.** Для каждого $\lambda_n$ решаем временное уравнение → $T_n(t)$.

**Шаг 6.** Общее решение — суперпозиция:
$$
u(x,t) = \sum_{n=1}^{\infty} C_n\, X_n(x)\, T_n(t).
$$

**Шаг 7.** Из начального условия находим коэффициенты $C_n$ через **разложение в ряд Фурье** по системе $\{X_n\}$.

## 3. Задача Штурма-Лиувилля

### Определение

**Формулировка (учебник):** задачей Штурма-Лиувилля называется краевая задача для ОДУ второго порядка:
$$
\frac{d}{dx}\left(p(x)\frac{dX}{dx}\right) + \bigl(q(x) + \lambda\,\rho(x)\bigr)X = 0, \qquad a < x < b,
$$
с граничными условиями на концах отрезка (Дирихле, Нейман, Робена или периодическими).

Здесь $p(x) > 0$, $\rho(x) > 0$ — заданные функции, $\lambda$ — параметр.

### Собственные значения и собственные функции

**Формулировка (учебник):** значения $\lambda$, при которых задача имеет ненулевые решения $X(x) \not\equiv 0$, называются **собственными значениями**, а соответствующие решения $X_n(x)$ — **собственными функциями**.

### Свойства

**Формулировка (учебник):**
1. Собственные значения вещественны и образуют неубывающую последовательность:
$$
\lambda_1 \le \lambda_2 \le \lambda_3 \le \ldots, \qquad \lambda_n \to +\infty.
$$
2. Собственные функции, соответствующие различным $\lambda_n$, **ортогональны** с весом $\rho(x)$:
$$
\int_a^b X_m(x)\, X_n(x)\, \rho(x)\, dx = 0, \qquad m \ne n.
$$
3. Система собственных функций **полна** в $L^2_\rho(a,b)$: любую кусочно-гладкую функцию можно разложить в ряд Фурье по $\{X_n\}$.

> [!tip] Простыми словами
> Собственные функции — как «базис» пространства функций. Любое начальное условие раскладывается по ним, и каждая мода эволюционирует независимо.

## 4. Пример: теплопроводность в стержне

### Постановка задачи

$$
u_t = \alpha\, u_{xx}, \qquad 0 < x < l,\; t > 0,
$$
$$
u(x,0) = \varphi(x), \qquad 0 \le x \le l,
$$
$$
u(0,t) = 0, \qquad u(l,t) = 0, \qquad t \ge 0.
$$
(Стержень с нулевой температурой на концах.)

### Шаг 1. Подстановка $u = X(x)T(t)$

$$
X(x)\,T'(t) = \alpha\, X''(x)\,T(t).
$$

### Шаг 2. Разделение переменных

Делим на $\alpha X T$:
$$
\frac{T'(t)}{\alpha\, T(t)} = \frac{X''(x)}{X(x)} = -\lambda.
$$
Левая часть зависит от $t$, правая — от $x$. Обе равны константе $-\lambda$ (выбираем знак «минус», чтобы решение затухало со временем).

### Шаг 3. Два ОДУ

**Пространственная задача Штурма-Лиувилля:**
$$
X'' + \lambda X = 0, \qquad X(0) = 0,\; X(l) = 0.
$$

**Временное уравнение:**
$$
T' + \alpha\lambda T = 0.
$$

### Шаг 4. Решение задачи Штурма-Лиувилля

Уравнение $X'' + \lambda X = 0$ с условиями $X(0) = X(l) = 0$.

- При $\lambda \le 0$: только тривиальное решение $X \equiv 0$.
- При $\lambda > 0$: общее решение $X = A\cos(\sqrt{\lambda}\,x) + B\sin(\sqrt{\lambda}\,x)$.
  - Из $X(0) = 0$: $A = 0$.
  - Из $X(l) = 0$: $B\sin(\sqrt{\lambda}\,l) = 0$ → $\sin(\sqrt{\lambda}\,l) = 0$ → $\sqrt{\lambda}\,l = n\pi$.

**Собственные значения и функции:**
$$
\lambda_n = \left(\frac{n\pi}{l}\right)^2, \qquad X_n(x) = \sin\frac{n\pi x}{l}, \qquad n = 1, 2, 3, \ldots
$$

### Шаг 5. Временное уравнение

$$
T'_n + \alpha\lambda_n T_n = 0 \;\Longrightarrow\; T_n(t) = e^{-\alpha\lambda_n t} = e^{-\alpha(n\pi/l)^2 t}.
$$

### Шаг 6. Общее решение

$$
u(x,t) = \sum_{n=1}^{\infty} C_n \sin\frac{n\pi x}{l}\; e^{-\alpha(n\pi/l)^2 t}.
$$

### Шаг 7. Коэффициенты из начального условия

При $t = 0$: $u(x,0) = \varphi(x) = \sum_{n=1}^{\infty} C_n \sin\frac{n\pi x}{l}$.

Это разложение $\varphi$ в ряд Фурье по синусам на $[0, l]$. Коэффициенты:
$$
C_n = \frac{2}{l}\int_0^l \varphi(x)\,\sin\frac{n\pi x}{l}\,dx.
$$

> [!tip] Простыми словами
> Начальная температура раскладывается на синусоидальные «моды». Каждая мода затухает экспоненциально со своей скоростью: высокие моды (большое $n$) затухают быстрее.

## 5. Пример: колебания струны

### Постановка задачи

$$
u_{tt} = c^2 u_{xx}, \qquad 0 < x < l,\; t > 0,
$$
$$
u(x,0) = \varphi(x), \qquad u_t(x,0) = \psi(x), \qquad 0 \le x \le l,
$$
$$
u(0,t) = 0, \qquad u(l,t) = 0, \qquad t \ge 0.
$$
(Струна с закреплёнными концами.)

### Разделение переменных

Подставляем $u = X(x)T(t)$:
$$
X\,T'' = c^2 X''\,T \;\Longrightarrow\; \frac{T''}{c^2 T} = \frac{X''}{X} = -\lambda.
$$

**Пространственная задача** та же: $X'' + \lambda X = 0$, $X(0) = X(l) = 0$:
$$
\lambda_n = \left(\frac{n\pi}{l}\right)^2, \qquad X_n(x) = \sin\frac{n\pi x}{l}.
$$

**Временное уравнение:**
$$
T''_n + c^2\lambda_n T_n = 0 \;\Longrightarrow\; T_n(t) = A_n\cos\omega_n t + B_n\sin\omega_n t,
$$
где $\omega_n = c\sqrt{\lambda_n} = \frac{cn\pi}{l}$ — собственная частота $n$-й моды.

### Общее решение

$$
u(x,t) = \sum_{n=1}^{\infty} \left(A_n\cos\omega_n t + B_n\sin\omega_n t\right)\sin\frac{n\pi x}{l}.
$$

Коэффициенты $A_n$, $B_n$ определяются из начальных условий:
$$
A_n = \frac{2}{l}\int_0^l \varphi(x)\sin\frac{n\pi x}{l}\,dx, \qquad B_n = \frac{2}{\omega_n l}\int_0^l \psi(x)\sin\frac{n\pi x}{l}\,dx.
$$

> [!tip] Простыми словами
> Струна колеблется как суперпозиция гармоник. Каждая гармоника — стоячая волна с частотой $\omega_n$. Основная частота $\omega_1 = \frac{c\pi}{l}$ определяет тон струны; обертоны $\omega_n = n\omega_1$ — тембр.

## 6. Пример: уравнение Лапласа в прямоугольнике

### Постановка задачи

$$
u_{xx} + u_{yy} = 0, \qquad 0 < x < a,\; 0 < y < b,
$$
$$
u(0,y) = 0, \qquad u(a,y) = 0, \qquad u(x,0) = 0, \qquad u(x,b) = f(x).
$$

### Разделение переменных

Ищем $u = X(x)Y(y)$:
$$
X''Y + XY'' = 0 \;\Longrightarrow\; \frac{X''}{X} = -\frac{Y''}{Y} = -\lambda.
$$

**Задача для $X$:** $X'' + \lambda X = 0$, $X(0) = X(a) = 0$:
$$
\lambda_n = \left(\frac{n\pi}{a}\right)^2, \qquad X_n(x) = \sin\frac{n\pi x}{a}.
$$

**Уравнение для $Y$:** $Y'' - \lambda_n Y = 0$, $Y(0) = 0$:
$$
Y_n(y) = \sinh\frac{n\pi y}{a}.
$$

### Общее решение

$$
u(x,y) = \sum_{n=1}^{\infty} C_n \sin\frac{n\pi x}{a}\,\sinh\frac{n\pi y}{a}.
$$

Из условия $u(x,b) = f(x)$:
$$
C_n = \frac{2}{a\,\sinh\frac{n\pi b}{a}}\int_0^a f(x)\sin\frac{n\pi x}{a}\,dx.
$$

## 7. Метод Даламбера (для волнового уравнения на прямой)

**Формулировка (учебник):** общее решение волнового уравнения $u_{tt} = c^2 u_{xx}$ на всей прямой имеет вид
$$
u(x,t) = F(x - ct) + G(x + ct),
$$
где $F$ и $G$ — произвольные дважды дифференцируемые функции. Это две бегущие волны: $F$ движется вправо со скоростью $c$, $G$ — влево.

Для задачи Коши $u(x,0) = \varphi(x)$, $u_t(x,0) = \psi(x)$:
$$
u(x,t) = \frac{\varphi(x-ct) + \varphi(x+ct)}{2} + \frac{1}{2c}\int_{x-ct}^{x+ct}\psi(s)\,ds.
$$

> [!tip] Простыми словами
> Даламбер — для бесконечной струны. Разделение переменных — для ограниченной (с границами). На прямой — нет собственных значений, спектр непрерывный; на отрезке — дискретный.

## 8. Связь с рядами Фурье

> [!tip] Простыми словами
> Метод разделения переменных приводит к **разложению в ряд Фурье** по собственным функциям. Это связь с [[14-Функциональные-последовательности-и-ряды-Ряды-Фурье|Вопросом 12]]:
> - Собственные функции $\{X_n\}$ образуют ортогональную систему.
> - Начальное условие раскладывается: $\varphi(x) = \sum C_n X_n(x)$.
> - Коэффициенты: $C_n = \frac{\int \varphi X_n}{\int X_n^2}$.
>
> Для задачи Штурма-Лиувилля с условиями Дирихле на $[0,l]$ собственные функции — синусы; с условиями Неймана — косинусы.

## 9. Типичные ошибки на экзамене

> [!failure] Частые ошибки
> Писать $u = X(x) + T(t)$ вместо произведения $X(x)T(t)$.
> Забывать разделить на $XT$ после подстановки.
> Неправильно выбирать знак константы разделения: для теплопроводности нужно $-\lambda$ (затухание), для волнового — тоже $-\lambda$ (колебания).
> Путать собственные значения: $\lambda_n = (n\pi/l)^2$, а не $n\pi/l$.
> Забывать, что для волнового уравнения временное решение — $\cos\omega_n t$ и $\sin\omega_n t$, а для теплопроводности — $e^{-\alpha\lambda_n t}$.
> Неправильно находить коэффициенты Фурье: забывать множитель $2/l$.
> Применять разделение переменных к нелинейным уравнениям (метод работает только для линейных).
> Не проверять граничные условия для $X(x)$: именно они определяют спектр.

### Образец устного ответа

> [!example] Устно (3–5 минут)
> 1. Основные методы: разделение переменных, Даламбер, характеристик, интегральные преобразования, функции Грина.
> 2. Метод разделения переменных: ищем $u = X(x)T(t)$, подставляем, делим на $XT$, получаем две части, зависящие от разных переменных → обе равны константе $-\lambda$.
> 3. Пространственная часть — задача Штурма-Лиувилля: $X'' + \lambda X = 0$ с граничными условиями. Собственные значения $\lambda_n = (n\pi/l)^2$, собственные функции $\sin(n\pi x/l)$.
> 4. Временная часть: для теплопроводности $T' + \alpha\lambda T = 0$ → $T = e^{-\alpha\lambda t}$; для волнового $T'' + c^2\lambda T = 0$ → $T = \cos\omega t, \sin\omega t$.
> 5. Общее решение: $u = \sum C_n X_n T_n$.
> 6. Коэффициенты $C_n$ — из начального условия через ряд Фурье: $C_n = \frac{2}{l}\int_0^l \varphi(x)\sin\frac{n\pi x}{l}\,dx$.
> 7. Свойства собственных функций: ортогональность, полнота.
> 8. Для волнового уравнения на прямой — формула Даламбера.

### Образец письменного ответа

> [!abstract] Письменно (структура для тетради / бланка)
> 1. **Обзор методов:** разделение переменных, Даламбер, характеристик, преобразования Фурье/Лапласа, функции Грина.
> 2. **Схема разделения переменных:**
>    - $u = X(x)T(t)$ → подстановка → деление на $XT$.
>    - $\frac{T'}{\alpha T} = \frac{X''}{X} = -\lambda$.
> 3. **Задача Штурма-Лиувилля:**
>    $$X'' + \lambda X = 0, \qquad X(0) = X(l) = 0.$$
>    Собственные значения: $\lambda_n = (n\pi/l)^2$.
>    Собственные функции: $X_n = \sin(n\pi x/l)$.
> 4. **Временное уравнение:**
>    - Теплопроводность: $T' + \alpha\lambda_n T = 0$ → $T_n = e^{-\alpha\lambda_n t}$.
>    - Волновое: $T'' + c^2\lambda_n T = 0$ → $T_n = A_n\cos\omega_n t + B_n\sin\omega_n t$.
> 5. **Общее решение:**
>    $$u(x,t) = \sum_{n=1}^{\infty} C_n X_n(x) T_n(t).$$
> 6. **Коэффициенты Фурье:**
>    $$C_n = \frac{2}{l}\int_0^l \varphi(x) X_n(x)\,dx.$$
> 7. **Свойства собственных функций:** ортогональность $\int X_m X_n = 0$ ($m \ne n$), полнота.
> 8. **Формула Даламбера:**
>    $$u(x,t) = \frac{\varphi(x-ct)+\varphi(x+ct)}{2} + \frac{1}{2c}\int_{x-ct}^{x+ct}\psi(s)\,ds.$$
