# Вопрос 48. Типы данных, способы задания. Константы и переменные

← [[00-MOC-Aspirantura-Prep]] · Предыдущий: [[47-Системы-и-языки-программирования]] · Программа: [[Вопросы#^q48|Вопросы]]

## Краткий ответ (для устного экзамена)

> [!abstract] Простыми словами — вся суть
> **Тип данных** = множество значений + допустимые операции + способ представления в памяти.
> **Классификация типов:**
>
> - **простые (скалярные):** целые, вещественные, символьные, логические;
> - **составные:** массивы, строки, записи;
> - **абстрактные (АТД):** списки, классы и т.п.
>   **Способы задания:** явное объявление типа (C++, Java) или динамическая типизация (Python).
>   **Константа** — значение не изменяется в ходе выполнения программы.
>   **Переменная** — именованная область памяти: имя + тип + значение + адрес.
>   Главные атрибуты переменной: имя, тип, значение, адрес; у константы — только значение и тип.
>   В C++: `int a = 5; const double PI = 3.14159;`
>   В Python: `a = 5`, `PI = 3.14159` (тип определяется автоматически).

## 1. Понятие типа данных

### Определение

**Формулировка (учебник):** тип данных — формальная характеристика данных, определяющая:

1. **множество допустимых значений** (домен);
2. **множество допустимых операций** над этими значениями;
3. **способ представления** в памяти компьютера.

### Три компонента типа

| Компонент        | Что определяет           | Пример для `int`                         |
| ---------------- | ------------------------ | ---------------------------------------- |
| Домен (значения) | какие значения допустимы | целые числа $-2^{31} \ldots 2^{31}-1$    |
| Операции         | что можно делать         | $+$, $-$, $*$, $/$ (целочисленное), $\%$ |
| Представление    | как хранится в памяти    | двоичное дополнение, 4 байта             |

> [!tip] Простыми словами
> Тип — это «паспорт данных»: говорит, что за значение, что с ним можно делать и сколько памяти оно занимает.

---

## 2. Классификация типов данных

### Общая схема

$$
\text{Типы данных}
\begin{cases}
\text{Простые (скалярные)} \\
\text{Составные (структурированные)} \\
\text{Абстрактные (АТД)}
\end{cases}
$$

### 2.1. Простые (скалярные) типы

| Тип          | Примеры значений | C++                    | Python                        |
| ------------ | ---------------- | ---------------------- | ----------------------------- |
| Целый        | $42$, $-7$       | `int`, `long`, `short` | `int`                         |
| Вещественный | $3.14$, $-0.5$   | `float`, `double`      | `float`                       |
| Символьный   | `'A'`, `'я'`     | `char`                 | `str` (одноэлементная строка) |
| Логический   | `True`, `False`  | `bool`                 | `bool`                        |

### 2.2. Составные (структурированные) типы

| Тип                | Описание                                 | Пример                          |
| ------------------ | ---------------------------------------- | ------------------------------- |
| Массив             | фиксированный набор однотипных элементов | `double a[10]`                  |
| Строка             | последовательность символов              | `std::string s`                 |
| Запись / структура | набор разнотипных полей                  | `struct Point { double x, y; }` |
| Кортеж             | неизменяемая последовательность          | `(1, 2, 3)` в Python            |

### 2.3. Абстрактные типы данных (АТД)

**Формулировка (учебник):** абстрактный тип данных — тип, определяемый через набор операций, без фиксации внутреннего представления.

Примеры: список, стек, очередь, дерево, множество, класс.

> [!tip] Простыми словами
> АТД — «чёрный ящик»: важно не как хранится, а какие операции доступны. Подробнее — [[50-Основы-объектно-ориентированного-программирования|Вопрос 50]] (ООП).

## 3. Способы задания типов

### Статическая и динамическая типизация

| Способ                     | Суть                                                     | Примеры языков       |
| -------------------------- | -------------------------------------------------------- | -------------------- |
| **Статическая** (явная)    | тип объявляется в коде и проверяется на этапе компиляции | C, C++, Java, Pascal |
| **Динамическая** (неявная) | тип определяется автоматически во время выполнения       | Python, JavaScript   |

### Примеры

**C++ (статическая типизация):**

```cpp
int a = 5;              // явно: целое
double x = 3.14;        // явно: вещественное
const double PI = 3.14159265;  // константа
```

**Python (динамическая типизация):**

```python
a = 5          # int определяется автоматически
x = 3.14       # float
PI = 3.14159265  # float (константа — по соглашению)
```

### Сильная и слабая типизация

| Характеристика | Суть                                                                     | Примеры       |
| -------------- | ------------------------------------------------------------------------ | ------------- |
| **Сильная**    | язык не позволяет смешивать несовместимые типы без явного преобразования | Python, Java  |
| **Слабая**     | неявные преобразования между типами допустимы                            | C, JavaScript |

> [!tip] Простыми словами
> Сильная типизация: «нельзя сложить число и строку без явного перевода». Слабая: «язык сам как-нибудь преобразует» (что может приводить к скрытым ошибкам).

## 4. Представление данных в памяти

### Целые числа

Хранятся в **двоичной системе**; отрицательные — в **дополнительном коде**.

| Тип (C++)   | Размер  | Диапазон                  |
| ----------- | ------- | ------------------------- |
| `int`       | 4 байта | $-2^{31} \ldots 2^{31}-1$ |
| `long long` | 8 байт  | $-2^{63} \ldots 2^{63}-1$ |

### Вещественные числа (IEEE 754)

**Формулировка (учебник):** число с плавающей точкой представляется в виде

$$
x = (-1)^s \cdot m \cdot 2^{\,e},
$$

где $s$ — знак, $m$ — мантисса, $e$ — порядок.

| Тип (C++) | Размер  | Точность                |
| --------- | ------- | ----------------------- |
| `float`   | 4 байта | $\sim 7$ значащих цифр  |
| `double`  | 8 байт  | $\sim 15$ значащих цифр |

> [!important] На экзамене
> Вещественные числа хранятся **приближённо**: $0.1 + 0.2 \ne 0.3$ в двоичной арифметике. Это источник ошибок округления в численных методах.

### Символы и логические

- Символы: коды таблиц (ASCII, Unicode) — целое число, отображённое на символ.
- Логические: `True` = 1, `False` = 0.

## 5. Константы

### Определение

**Формулировка (учебник):** константа — именованное или литеральное значение, **не изменяемое** в процессе выполнения программы.

### Виды констант

| Вид              | Пример (C++)                 | Пример (Python)                |
| ---------------- | ---------------------------- | ------------------------------ |
| **Литеральная**  | `42`, `3.14`, `'A'`          | `42`, `3.14`, `"hello"`        |
| **Именованная**  | `const double PI = 3.14159;` | `PI = 3.14159` (по соглашению) |
| **Макрос**       | `#define N 100`              | —                              |
| **Перечисление** | `enum Color { RED, GREEN };` | `from enum import Enum`        |

### Константы в C++

```cpp
const int MAX_SIZE = 1000;      // нельзя изменить
constexpr double PI = 3.14159;  // известно на этапе компиляции
```

### Константы в Python

В Python нет синтаксиса «настоящей» константы — используется **соглашение** (имя заглавными буквами):

```python
MAX_SIZE = 1000   # константа по соглашению
PI = 3.14159265
```

> [!tip] Простыми словами
> В C++ `const` — «запрет на изменение» enforced компилятором. В Python `PI = 3.14` — просто договорённость между программистами.

## 6. Переменные

### Определение

**Формулировка (учебник):** переменная — именованная область памяти, имеющая **имя**, **тип**, **значение** и **адрес**; значение может изменяться в процессе выполнения программы.

### Атрибуты переменной

| Атрибут                 | Что это                  | Пример       |
| ----------------------- | ------------------------ | ------------ |
| **Имя** (идентификатор) | как обращаемся           | `counter`    |
| **Тип**                 | какие значения допустимы | `int`        |
| **Значение**            | текущее содержимое       | `42`         |
| **Адрес**               | где лежит в памяти       | `0x7ffee...` |

### Объявление и инициализация

**C++:**

```cpp
int a;          // объявление (без инициализации)
int b = 10;     // объявление + инициализация
double x = 0.0;
```

**Python:**

```python
a = 10          # создаётся и инициализируется
x = 0.0
```

### Область видимости и время жизни

| Характеристика        | Суть                                             |
| --------------------- | ------------------------------------------------ |
| **Область видимости** | где в коде переменная доступна                   |
| **Время жизни**       | когда память под переменную выделена/освобождена |

Виды переменных по области видимости:

- **локальные** — внутри функции, живут пока функция работает;
- **глобальные** — видны во всём модуле;
- **статические** — сохраняют значение между вызовами.

> [!tip] Простыми словами
> Локальная переменная — «жилец квартиры»: появилась при вызове функции, исчезла при выходе. Глобальная — «житель дома»: существует всё время работы программы.

## 7. Сравнение: константа vs переменная

| Критерий             | Константа                                | Переменная                    |
| -------------------- | ---------------------------------------- | ----------------------------- |
| Изменение значения   | запрещено                                | разрешено                     |
| Ключевые слова (C++) | `const`, `constexpr`                     | —                             |
| Соглашение (Python)  | ЗАГЛАВНЫЕ_БУКВЫ                          | строчные_буквы                |
| Назначение           | фиксированные параметры (π, размерности) | изменяемые данные в алгоритме |

## 8. Примеры в контексте численных методов

### C++ (разностная схема из [[46-Разностные-методы-решения-нестационарных-задач-математической-физики|Вопроса 46]])

```cpp
const int N = 100;          // число узлов сетки — константа
const double a = 1.0;       // коэффициент теплопроводности
double h = 1.0 / N;         // шаг по пространству — переменная
double tau = 0.5 * h * h;   // шаг по времени — переменная
double u[N];                // массив — составной тип
```

### Python (аналог)

```python
N = 100          # константа по соглашению
a = 1.0
h = 1.0 / N
tau = 0.5 * h * h
u = [0.0] * N    # список (составной тип)
```

> [!tip] Простыми словами
> В численных расчётах константы — это физические параметры и размеры сеток, переменные — шаги, текущие значения решения, счётчики циклов.

## 9. Типичные ошибки на экзамене

> [!failure] Частые ошибки
> Путать **тип данных** (множество значений + операции + представление) и **переменную** (именованная область памяти определённого типа).
> Считать, что в Python нет типов — они есть, но определяются динамически.
> Утверждать, что `const` в C++ и заглавное имя в Python — одно и то же: в Python это только соглашение.
> Забывать, что вещественные числа хранятся приближённо (IEEE 754).
> Путать **объявление** (`int a;`) и **инициализацию** (`a = 5`).
> Не различать область видимости и время жизни переменной.
> Не приводить примеры из конкретных языков (C++, Python).

## 13. Как должен выглядеть ответ на экзамене

### Образец устного ответа

> [!example] Устно (3–5 минут)
>
