# Словарь математических записей

← [[00-MOC-Aspirantura-Prep]] · Билеты: [[Билеты]] · Карточки: [[Flashcards-All-Questions]]

Записи в том виде, в каком их ждут **на доске и в черновике билета**. В скобках — как произносить вслух.

> [!tip] На экзамене
> Сначала **определение словами**, сразу под ним **формула**. Кванторы писать в порядке $\forall\varepsilon\ \exists N\ \forall n$, не наоборот.

---

## 1. Логика и кванторы

| Запись | Смысл | Говорить |
| --- | --- | --- |
| $\forall$ | для любого | «для любого», «для всякого» |
| $\exists$ | существует | «существует» |
| $\exists!$ | существует единственный | «существует единственный» |
| $\Rightarrow$ | следует | «следует», «влечёт» |
| $\Leftrightarrow$ | равносильно | «тогда и только тогда», «эквивалентно» |
| $\iff$ | то же | то же |
| $\land$, $\lor$, $\neg$ | и, или, не | редко на доске; лучше словами |
| $:\quad$ / $\mid$ | такое, что | «такое, что» |
| $\in$, $\notin$ | принадлежит / не принадлежит | «лежит в», «не лежит в» |
| $\subset$, $\subseteq$ | подмножество | «содержится в» |
| $\cup$, $\cap$ | объединение, пересечение | |
| $\emptyset$ | пустое множество | |
| $\square$ | конец доказательства | «что и требовалось» |

Типичная $\varepsilon$–$N$ строка:

$$
\forall\,\varepsilon>0\ \ \exists\,N\in\mathbb{N}\ \ \forall\,n>N:\quad |x_n-a|<\varepsilon.
$$

## 2. Числа, множества, нормы

| Запись                                                           | Смысл                                                       |
| ---------------------------------------------------------------- | ----------------------------------------------------------- |
| $\mathbb{N},\ \mathbb{Z},\ \mathbb{Q},\ \mathbb{R},\ \mathbb{C}$ | натуральные, целые, рациональные, вещественные, комплексные |
| $[a,b]$, $(a,b)$, $[a,b)$                                        | отрезок, интервал, полуинтервал                             |
| $\mathbb{R}^n$                                                   | столбцы длины $n$                                           |
| $C[a,b]$                                                         | непрерывные на $[a,b]$                                      |
| $C^k[a,b]$                                                       | $k$ раз непрерывно дифференцируемые                         |
| $L^2[a,b]$                                                       | $\displaystyle\int_a^bf^2<\infty$                           |
| $\|x\|$, $\|x\|_p$, $\|x\|_\infty$                               | норма; $\ell_p$; максимум модуля координат                  |
| $\|f\|_{C}$, $\|f\|_{L^2}$                                       | $\max f$; $\sqrt{\int f^2}$                                 |
| $O(h^p)$, $o(h)$                                                 | не выше $h^p$; бесконечно малое сильнее $h$                 |
| $\delta_{ij}$                                                    | символ Кронекера: $1$ при $i=j$, иначе $0$                  |

Неравенство треугольника: $\|x+y\|\le\|x\|+\|y\|$.

Эквивалентность норм в $\mathbb{R}^n$: $c_1\|x\|_a\le\|x\|_b\le c_2\|x\|_a$.

## 3. Предел, непрерывность, производная

| Запись | Смысл |
| --- | --- |
| $\lim_{n\to\infty}x_n=a$ | предел последовательности |
| $x_n\to a$ | то же |
| $\lim_{x\to x_0}f(x)=A$ | предел функции |
| $x\to x_0+$, $x\to x_0-$ | справа / слева |
| $f\in C(x_0)$ | непрерывна в точке |
| $f\in C[a,b]$ | непрерывна на отрезке |
| $f'(x)$, $\dfrac{df}{dx}$ | производная |
| $f^{(n)}(x)$ | $n$-я производная |
| $df=f'(x)\,dx$ | дифференциал |
| $D(a,b)$ | дифференцируема на интервале |

Критерий Коши для последовательности: $\forall\varepsilon>0\ \exists N:\ \forall m,n>N\ \Rightarrow\ |x_m-x_n|<\varepsilon$.

Лагранж:

$$
f(b)-f(a)=f'(c)(b-a),\qquad c\in(a,b).
$$

Тейлор с остатком Лагранжа:

$$
f(x)=\sum_{k=0}^{n}\frac{f^{(k)}(x_0)}{k!}(x-x_0)^k+\frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}.
$$

Ньютон–Лейбниц:

$$
\int_a^b f(x)\,dx=F(b)-F(a),\qquad F'=f.
$$

## 4. Ряды и Фурье

| Запись                        | Смысл                     |
| ----------------------------- | ------------------------- |
| $\sum_{n=1}^\infty a_n$       | числовой ряд              |
| $s_n=\sum_{k=1}^n a_k$        | частичная сумма           |
| $\sum a_n$ сходится абсолютно | $\sum\|a_n\|<\infty$      |
| условно                       | сходится, но не абсолютно |
| $\sum_{n=1}^\infty u_n(x)$    | функциональный ряд        |
| равномерная сходимость        | $\sup_x\|r_n(x)\|\to 0$   |

Признак Даламбера: $\lim\bigl|\frac{a_{n+1}}{a_n}\bigr|=q<1$ ⇒ сходимость.

Ряд Фурье на $[-\pi,\pi]$:

$$
\frac{a_0}{2}+\sum_{n=1}^\infty\bigl(a_n\cos nx+b_n\sin nx\bigr).
$$

$$
a_n=\frac{1}{\pi}\int_{-\pi}^{\pi}f(x)\cos nx\,dx,\quad
b_n=\frac{1}{\pi}\int_{-\pi}^{\pi}f(x)\sin nx\,dx.
$$

## 5. Функции многих переменных и поле

| Запись | Смысл |
| --- | --- |
| $f:\mathbb{R}^n\to\mathbb{R}$ | скалярная функция |
| $x=(x_1,\ldots,x_n)$ | точка |
| $\dfrac{\partial f}{\partial x_i}$, $f_{x_i}$ | частная производная |
| $\nabla f=\operatorname{grad} f$ | градиент $(\partial_{x_1}f,\ldots)$ |
| $\dfrac{\partial f}{\partial \ell}=(\nabla f,\ell)$ | производная по направлению ($\|\ell\|=1$) |
| $df=\sum\dfrac{\partial f}{\partial x_i}dx_i$ | полный дифференциал |
| $d^2f$, форма Гессе $H$ | второй дифференциал; $H_{ij}=\partial_{x_i x_j}f$ |
| $\operatorname{div} A$ | дивергенция |
| $\operatorname{rot} A$, $\nabla\times A$ | ротор |
| $\Delta u=\operatorname{div}\operatorname{grad} u$ | лапласиан |
| $\oint$, $\iint_S$ | криволинейный / поверхностный интеграл |

Цепное правило: если $u=f(x(t),y(t))$, то

$$
\frac{du}{dt}=\frac{\partial f}{\partial x}\frac{dx}{dt}+\frac{\partial f}{\partial y}\frac{dy}{dt}.
$$

Необходимое условие экстремума: $\nabla f=0$ (стационарная точка).

## 6. Линейная алгебра

| Запись                                 | Смысл                                       |
| -------------------------------------- | ------------------------------------------- |
| $V$, $\dim V$                          | пространство, размерность                   |
| $\mathcal{L}(v_1,\ldots,v_k)$          | линейная оболочка                           |
| $A\in\mathbb{R}^{m\times n}$, $a_{ij}$ | матрица, элемент                            |
| $A^T$, $A^{-1}$, $A^+$                 | транспонированная, обратная, псевдообратная |
| $\det A$, $A$                          | определитель                                |
| $\operatorname{rank} A$                | ранг                                        |
| $E$ или $I$                            | единичная матрица                           |
| $Ax=b$, $(A\mid b)$                    | СЛАУ, расширенная матрица                   |
| $\ker A$, $\operatorname{Im} A$        | ядро, образ                                 |
| $Av=\lambda v$                         | собственное значение / вектор               |
| $A=Q\Lambda Q^{-1}$                    | диагонализация                              |
| $(u,v)$, $u\perp v$                    | скалярное произведение; ортогональность     |
| $\|u\|=\sqrt{(u,u)}$                   | норма из скалярного произведения            |

Кронекер–Капелли: $Ax=b$ совместна $\iff\operatorname{rank} A=\operatorname{rank}(A\mid b)$.

Характеристическое уравнение: $\det(A-\lambda E)=0$.

## 7. ОДУ и уравнения матфизики

| Запись                                                 | Смысл                                                |
| ------------------------------------------------------ | ---------------------------------------------------- |
| $y'=f(x,y)$, $y(x_0)=y_0$                              | задача Коши для ОДУ                                  |
| $y''+p(x)y'+q(x)y=g(x)$                                | линейное ОДУ 2-го порядка                            |
| $\dot x=Ax$                                            | линейная однородная система                          |
| $u_t$, $u_{xx}$                                        | $\partial u/\partial t$, $\partial^2 u/\partial x^2$ |
| $Lu=f$                                                 | дифференциальный оператор                            |
| $\Delta u=0$                                           | уравнение Лапласа (эллиптическое)                    |
| $u_t=a^2 u_{xx}$                                       | теплопроводность (параболическое)                    |
| $u_{tt}=a^2 u_{xx}$                                    | волна (гиперболическое)                              |
| $u=g$ на $\partial\Omega$                              | условие Дирихле                                      |
| $\dfrac{\partial u}{\partial n}=g$ на $\partial\Omega$ | условие Неймана                                      |
| $u(x,0)=\varphi(x)$, $u_t(x,0)=\psi(x)$                | начальные данные (Коши / смесь)                      |

На доске те же условия пишут со следом на границе. Вертикальную черту нельзя ставить внутрь ячейки таблицы — Markdown принимает её за новую колонку:

$$
u\big|_{\partial\Omega}=g,
\qquad
\frac{\partial u}{\partial n}\Big|_{\partial\Omega}=g.
$$

Классификация УЧП 2-го порядка по знаку $\delta=b^2-ac$ (для $a u_{xx}+2b u_{xy}+c u_{yy}+\cdots=0$):

- $\delta<0$ — эллиптический тип;
- $\delta=0$ — параболический;
- $\delta>0$ — гиперболический.

Разделение переменных: $u(x,t)=X(x)T(t)$.

## 8. Численные методы и сетки

| Запись | Смысл |
| --- | --- |
| $h$, $\tau$ | шаг по пространству / по времени |
| $x_i=ih$, $t^n=n\tau$ | узлы сетки |
| $y_i^n\approx u(x_i,t^n)$ | сеточная функция |
| $L_h y=\varphi$ | разностная схема |
| $\psi=L_h u-\varphi$ | невязка (погрешность аппроксимации) |
| $\psi=O(h^p+\tau^q)$ | порядок аппроксимации |
| $y_{\bar x}=\dfrac{y_i-y_{i-1}}{h}$ | левая разность |
| $y_x=\dfrac{y_{i+1}-y_i}{h}$ | правая разность |
| $y_{\overset{\circ}{x}}=\dfrac{y_{i+1}-y_{i-1}}{2h}$ | центральная |
| $y_{\bar x x}=\dfrac{y_{i+1}-2y_i+y_{i-1}}{h^2}$ | вторая разность |
| $\sigma=\tau/h^2$ | число Куранта для теплопроводности |
| $r=c\tau/h$ | число Куранта для волны |

Аппроксимация:

$$
\frac{u_{i+1}-u_i}{h}=u_x+O(h),\qquad
\frac{u_{i+1}-2u_i+u_{i-1}}{h^2}=u_{xx}+O(h^2).
$$

Устойчивость (схема не усиливает возмущения):

$$
\|y\|\le C\,(\|\text{вход}\|).
$$

Теорема Лакса (для линейных корректных задач):

$$
\text{аппроксимация}+\text{устойчивость}\ \Longrightarrow\ \text{сходимость}.
$$

Сходимость: $\|y-u_h\|\to 0$ при $h,\tau\to 0$ ($u_h$ — проекция точного решения на сетку).

Метод гармоник: $y_i^n=q^n e^{i\xi x_i}$, нужно $|q(\xi)|\le 1$.

Итерации для СЛАУ: $x^{k+1}=Bx^k+c$; сходится, если $\rho(B)<1$ (спектральный радиус).

Ньютон: $x_{k+1}=x_k-\dfrac{f(x_k)}{f'(x_k)}$.

Эйлер: $y_{n+1}=y_n+\tau f(t_n,y_n)$.

## 9. Как писать ответ в билете

Шаблон на один вопрос:

1. **Название.** «Предел последовательности по Коши».
2. **Формула-определение** одной строкой.
3. **Что из этого следует** (1–2 теоремы).
4. **Картинка или пример** (график, сетка, матрица $2\times 2$).
5. **Связь со специальностью**, если вопрос из 1–34: «это оценка невязки / норма в устойчивости / ряд Фурье в разделении переменных».

Частые описки на доске:

| Пишут | Надо |
| --- | --- |
| $\forall n\ \exists\varepsilon$ | сначала $\varepsilon$, потом $N$ |
| $O(h)=o(h)$ | $o$ сильнее, чем $O$ |
| устойчивость без нормы | указать, **в какой** норме |
| $u_{xx}$ и $u_{\bar x x}$ как одно и то же | одно — непрерывное, другое — сеточное |
| $\det A\neq 0$ ⇒ любые СЛАУ | только квадратные; для прямоугольных — ранг |

## 10. Греческий алфавит (то, что реально пишут)

| Буква | Типичная роль в этой программе |
| --- | --- |
| $\varepsilon,\delta$ | точность в определениях предела |
| $\xi$ | промежуточная точка (Лагранж, Тейлор) |
| $\lambda$ | собственное значение; параметр разделения |
| $\mu$ | иногда второе собственное / шаг итерации |
| $\tau,h$ | шаги сетки |
| $\varphi,\psi$ | начальные данные; невязка $\psi$ |
| $\sigma$ | $\tau/h^2$ |
| $\Omega,\partial\Omega$ | область и граница |
| $\rho(B)$ | спектральный радиус |
| $\Delta$ | лапласиан или приращение |
| $\nabla$ | градиент / набла |
