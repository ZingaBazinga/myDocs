# Вопрос 49. Выражения, операции, операторы. Арифметические и логические операции и операторы

← [[00-MOC-Aspirantura-Prep]] · Предыдущий: [[48-Типы-данных-константы-и-переменные]] · Программа: [[Вопросы программы вступительного экзамена в аспирантуру по специальности 1.2.2. Математическое моделирование, численные методы и комплексы программ]]

## Краткий ответ (для устного экзамена)

> [!abstract] Простыми словами — вся суть
> **Выражение** — комбинация операндов и операций, дающая значение: `a + b * 2`.
> **Операция** — действие над данными (сложение, сравнение, логическое И).
> **Оператор** — символ операции (`+`, `&&`) или инструкция языка (`if`, `while`).
> **Арифметические операции:** $+$, $-$, $*$, $/$, целочисленное деление `//`, остаток `%`, возведение в степень `**`.
> **Логические операции:** И (`and`/`&&`), ИЛИ (`or`/`||`), НЕ (`not`/`!`).
> **Приоритет операций:** скобки → унарные → мультипликативные → аддитивные → сравнения → логические.
> Выражения вычисляются, операторы исполняются. Результат логической операции — `True`/`False`, арифметической — число.

## 1. Понятие выражения

### Определение

**Формулировка (учебник):** выражение — синтаксически корректная комбинация **операндов** (констант, переменных, вызовов функций) и **операций**, результатом вычисления которой является значение.

### Структура выражения

$$
\text{Выражение} = \text{операнды} + \text{операции}
$$

| Компонент | Что это | Пример |
| --- | --- | --- |
| Операнд | данные, над которыми выполняется операция | `a`, `5`, `f(x)` |
| Операция | действие над операндами | `+`, `*`, `>` |
| Результат | значение выражения | число, логическое значение |

### Примеры выражений

| Выражение | Тип результата |
| --- | --- |
| `a + b` | арифметическое (число) |
| `x > 0` | логическое (`True`/`False`) |
| `a == b && c != 0` | логическое (составное) |
| `sqrt(x*x + y*y)` | арифметическое (вызов функции) |

> [!tip] Простыми словами
> Выражение — это «вопрос, на который можно вычислить ответ». `2 + 3` отвечает `5`; `x > 0` отвечает «да» или «нет».

### Свойства выражений

| Свойство | Суть |
| --- | --- |
| **Тип** | определяется типами операндов и операций |
| **Значение** | результат вычисления |
| **Порядок вычисления** | определяется приоритетом и ассоциативностью |
| **Побочные эффекты** | изменение состояния (например, присваивание внутри выражения) |

## 2. Операции и операторы: терминология

### Разграничение понятий

| Термин | Значение | Пример |
| --- | --- | --- |
| **Операция** (operation) | действие над данными | сложение |
| **Оператор** (operator) | символ, обозначающий операцию | `+` |
| **Оператор** (statement) | инструкция языка | `if (...) {...}`, `while (...) {...}` |

> [!important] На экзамене
> В русском языке слово «оператор» многозначно:
> - оператор как символ операции: `+`, `*`;
> - оператор как инструкция: `if`, `for`, `return`.
> Уточняйте контекст.

### Классификация операций

| Класс операций | Назначение | Примеры |
| --- | --- | --- |
| Арифметические | числовые вычисления | `+`, `-`, `*`, `/`, `%` |
| Сравнения | отношение между значениями | `==`, `!=`, `<`, `>`, `<=`, `>=` |
| Логические | булева алгебра | `and`, `or`, `not` |
| Присваивания | изменение значения | `=`, `+=`, `-=` |
| Побитовые | операции над битами | `&`, `|`, `^`, `<<`, `>>` |
| Унарные | один операнд | `-x`, `!x`, `++x` |

### Арность операций

| Арность | Число операндов | Пример |
| --- | --- | --- |
| Унарная | 1 | `-x`, `not a` |
| Бинарная | 2 | `a + b`, `x > y` |
| Тернарная | 3 | `cond ? a : b` (C++), `a if cond else b` (Python) |

## 3. Арифметические операции

### Бинарные арифметические операции

| Операция | C++ | Python | Результат |
| --- | --- | --- | --- |
| Сложение | `a + b` | `a + b` | сумма |
| Вычитание | `a - b` | `a - b` | разность |
| Умножение | `a * b` | `a * b` | произведение |
| Деление | `a / b` | `a / b` | частное |
| Целочисленное деление | — | `a // b` | целая часть |
| Остаток от деления | `a % b` | `a % b` | остаток |
| Возведение в степень | `pow(a,b)` | `a ** b` | $a^b$ |

### Особенности деления

**C++:**
```cpp
int a = 7 / 2;      // a = 3 (целочисленное деление)
double b = 7.0 / 2; // b = 3.5
```

**Python:**
```python
7 / 2    # 3.5 (обычное деление → float)
7 // 2   # 3 (целочисленное деление)
7 % 2    # 1 (остаток)
```

### Унарные арифметические операции

| Операция | Смысл | Пример |
| --- | --- | --- |
| Унарный минус | смена знака | `-x` |
| Унарный плюс | обычно ничего не меняет | `+x` |
| Инкремент / декремент (C++) | увеличение/уменьшение на 1 | `++i`, `--i` |

> [!tip] Простыми словами
> Арифметика в программировании повторяет школьную, но добавляет целочисленное деление `//` и остаток `%` — они нужны для работы с индексами, сетками, чётностью.

### Применение в численных методах

В разностных схемах ([[46-Разностные-методы-решения-нестационарных-задач-математической-физики|Вопрос 46]]) типичные выражения:
```python
sigma = a*a * tau / h**2          # параметр устойчивости
u_new = (1 - 2*sigma)*u + sigma*(u_left + u_right)
```

## 4. Операции сравнения

### Таблица операций сравнения

| Отношение | C++ | Python | Результат |
| --- | --- | --- | --- |
| Равно | `a == b` | `a == b` | `True`, если равны |
| Не равно | `a != b` | `a != b` | `True`, если не равны |
| Меньше | `a < b` | `a < b` | `True`, если $a < b$ |
| Больше | `a > b` | `a > b` | `True`, если $a > b$ |
| Меньше или равно | `a <= b` | `a <= b` | `True`, если $a \le b$ |
| Больше или равно | `a >= b` | `a >= b` | `True`, если $a \ge b$ |

> [!important] На экзамене
> Не путайте `=` (присваивание) и `==` (сравнение). Классическая ошибка: `if (a = b)` вместо `if (a == b)`.

### Особенности

- В C++ результат сравнения — `bool` (`true`/`false`).
- В Python результат — `True`/`False`; допустимы цепочки: `a < b < c`.
- Сравнение вещественных чисел требует осторожности из-за погрешности IEEE 754 ([[48-Типы-данных-константы-и-переменные|Вопрос 48]]).

> [!tip] Простыми словами
> Вещественные числа нельзя сравнивать «в лоб»: вместо `x == y` проверяйте `abs(x - y) < eps`.

## 5. Логические операции

### Булева алгебра в программировании

| Операция | Обозначение (математика) | C++ | Python | Смысл |
| --- | --- | --- | --- | --- |
| И (конъюнкция) | $A \land B$ | `A && B` | `A and B` | истинно, если оба истинны |
| ИЛИ (дизъюнкция) | $A \lor B$ | `A \|\| B` | `A or B` | истинно, если хотя бы одно истинно |
| НЕ (отрицание) | $\lnot A$ | `!A` | `not A` | инверсия |

### Таблицы истинности

| $A$ | $B$ | $A \land B$ | $A \lor B$ | $\lnot A$ |
| --- | --- | --- | --- | --- |
| 0 | 0 | 0 | 0 | 1 |
| 0 | 1 | 0 | 1 | 1 |
| 1 | 0 | 0 | 1 | 0 |
| 1 | 1 | 1 | 1 | 0 |

### Примеры

**C++:**
```cpp
bool inRange = (x >= 0) && (x <= 1);   // x в [0, 1]
bool notZero = (x != 0) || (y != 0);   // не оба нуля
```

**Python:**
```python
in_range = 0 <= x <= 1          # цепочка сравнений
not_zero = (x != 0) or (y != 0)
```

### Ленивые (короткие) вычисления

**Формулировка (учебник):** в выражениях `A && B` и `A || B` второй операнд может не вычисляться:
- `A && B`: если `A` ложно, результат уже ложный → `B` не вычисляется.
- `A || B`: если `A` истинно, результат уже истинный → `B` не вычисляется.

> [!tip] Простыми словами
> «И» останавливается на первом «нет»; «ИЛИ» останавливается на первом «да». Это важно, если второй операнд — функция с побочным эффектом.

## 6. Приоритет операций

### Порядок выполнения (от высшего к низшему)

| Приоритет | Операции | Пример |
| --- | --- | --- |
| 1 (высший) | Скобки `( )` | `(a + b) * c` |
| 2 | Унарные `-`, `!`, `not` | `-x`, `not a` |
| 3 | Мультипликативные `*`, `/`, `%` | `a * b / c` |
| 4 | Аддитивные `+`, `-` | `a + b - c` |
| 5 | Сравнения `<`, `>`, `<=`, `>=` | `a + b < c` |
| 6 | Равенство `==`, `!=` | `x == y` |
| 7 | Логическое И `&&` / `and` | `a && b` |
| 8 (низший) | Логическое ИЛИ `\|\|` / `or` | `a \|\| b` |

### Пример разбора выражения

$$
x = a + b * c > d \;\;\text{и}\;\; e
$$

Порядок:
1. `b * c` (мультипликативная);
2. `a + (b*c)` (аддитивная);
3. `(a + b*c) > d` (сравнение);
4. `... && e` (логическое И).

> [!tip] Простыми словами
> Сначала умножаем, потом складываем, потом сравниваем, потом применяем логику. Скобки — способ не запоминать приоритеты.

## 7. Операторы (инструкции языка)

### Определение

**Формулировка (учебник):** оператор (statement) — элементарная инструкция языка программирования, описывающая одно действие или шаг вычислительного процесса.

### Основные виды операторов

| Вид оператора | Назначение | Пример (C++) | Пример (Python) |
| --- | --- | --- | --- |
| **Присваивание** | изменить значение | `x = 5;` | `x = 5` |
| **Составное присваивание** | операция + присваивание | `x += 1;` | `x += 1` |
| **Условный** | ветвление | `if (x > 0) {...}` | `if x > 0: ...` |
| **Цикл** | повторение | `for`, `while` | `for`, `while` |
| **Возврат** | выход из функции | `return x;` | `return x` |
| **Пустой** | ничего не делать | `;` | `pass` |

### Оператор присваивания

**Формулировка (учебник):** оператор присваивания вычисляет выражение справа и записывает результат в переменную слева:
$$
x \mathrel{:=} E
$$

| Форма | Смысл |
| --- | --- |
| `x = E` | простое присваивание |
| `x += E` | `x = x + E` |
| `x -= E` | `x = x - E` |
| `x *= E` | `x = x * E` |
| `x /= E` | `x = x / E` |

### Условный оператор

**C++:**
```cpp
if (x > 0) {
    y = 1;
} else {
    y = -1;
}
```

**Python:**
```python
if x > 0:
    y = 1
else:
    y = -1
```

### Операторы цикла

| Цикл | C++ | Python |
| --- | --- | --- |
| С предусловием | `while (cond) {...}` | `while cond: ...` |
| С параметром | `for (int i = 0; i < N; ++i) {...}` | `for i in range(N): ...` |

> [!tip] Простыми словами
> Выражения **вычисляются** (дают значение), операторы **исполняются** (делают действие). `a + b` — выражение; `x = a + b;` — оператор присваивания с выражением справа.

## 8. Примеры в контексте численных методов

### Вычисление шага сетки и параметра устойчивости

**Python:**
```python
h = 1.0 / N                       # арифметика: деление
tau = 0.5 * h**2                  # степень, умножение
sigma = a*a * tau / (h*h)         # композиция операций

if sigma <= 0.5:                  # сравнение + логика в условии
    print("схема устойчива")
```

### Проверка условия Куранта ([[46-Разностные-методы-решения-нестационарных-задач-математической-физики|Вопрос 46]])

```python
courant = a * tau / h
stable = courant <= 1.0           # логическое выражение
```

### Цикл по узлам сетки

```python
for i in range(1, N):             # оператор цикла
    u_new[i] = (1 - 2*sigma)*u[i] + sigma*(u[i-1] + u[i+1])
```

> [!tip] Простыми словами
> Вся численная схема — это композиция арифметических выражений внутри операторов цикла и условий.

## 9. Типичные ошибки на экзамене

> [!failure] Частые ошибки
> Путать `=` (присваивание) и `==` (сравнение).
> Считать, что `a < b < c` работает в C++ как в Python — в C++ это `(a < b) < c`, что даёт сравнение логического значения с `c`.
> Забывать про приоритет операций: `a & b == c` интерпретируется как `a & (b == c)`.
> Не учитывать целочисленное деление: `7 / 2` в C++ для целых даёт `3`, а не `3.5`.
> Сравнивать вещественные числа на точное равенство без учёта погрешности.
> Путать унарный минус `-x` и бинарное вычитание `a - b`.
> Не помнить про ленивые вычисления: второй операнд `&&`/`and` может не вычисляться.
> Смешивать термины «операция», «оператор-символ», «оператор-инструкция».

| Арифметика | `+ - * / // % **` | примеры кода |
| Сравнение | `== != < > <= >=` | таблица |

| Приоритет | скобки → `*` → `+` → логика | таблица приоритетов |
| Операторы-инструкции | `if`, `for`, `while`, `=` | примеры кода |
