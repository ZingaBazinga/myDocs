# JavaScript — уровень Middle

База: [[09-Конспект-Junior-база#JavaScript]]. Здесь — расширение до Middle.

---

## Паттерны проектирования (кратко с примерами применения на фронте)

| Паттерн | Суть | Фронт |
|---------|------|--------|
| **Module** | Инкапсуляция через замыкания или ES modules | Публичный API модуля |
| **Observer / Pub-Sub** | Подписка на события | EventEmitter, RxJS, события DOM |
| **Factory** | Создание объектов без указания точного класса | Фабрики конфигов компонентов |
| **Singleton** | Один экземпляр | Логгер, конфиг (осторожно с тестами) |
| **Strategy** | Взаимозаменяемые алгоритмы | Стратегии валидации, форматирования |
| **Decorator** | Обёртка поверх объекта | HOC в React, декораторы (stage 3 TS) |
| **Proxy** | Перехват операций | Реактивность Vue 3, валидация |
| **Iterator** | Единообразный обход | Протокол итерируемых объектов |
| **Command** | Инкапсуляция действия | Undo/redo, очереди задач |

Не заучивай имена — на собеседовании важнее **признать паттерн в коде** и назвать trade-offs.

---

## SOLID (практика на фронте)

- **S** — один модуль/компонент отвечает за одну причину изменения (раздели UI и загрузку данных — смарт/глупые компоненты).
- **O** — расширяемость через композицию/пропсы без постоянного редактирования базового класса.
- **L** — подтипы не должны ломать ожидания (пропсы совместимы).
- **I** — узкие интерфейсы пропсов vs один «бог-объект».
- **D** — зависимость от абстракций (интерфейсы сервисов, DI в тестах).

---

## DRY, KISS, YAGNI

- **DRY** — не дублируй; но не создавай преждевременные абстракции.
- **KISS** — проще решение часто лучше сложного «на вырост».
- **YAGNI** — не кодь фичи «на будущее» без запроса.

---

## Event Loop: глубже

**Микрозадачи:** промисы, `queueMicrotask`, мутации наблюдаемого — выполняются **после текущего синхронного кода**, но до следующей макрозадачи.

**Макрозадачи:** `setTimeout`, `setInterval`, I/O callbacks.

**`requestAnimationFrame`** — перед repaint; часто цепочка: задачи → микрозадачи → rAF → отрисовка.

**`requestIdleCallback`** — низкоприоритетные задачи в простое (не для критичного UI; поддержка не везде).

Порядок типичного тика: синхронный код → все microtasks → возможно рендер → macrotask следующая.

---

## Браузерный рендеринг

Пайплайн: **DOM + CSSOM → дерево рендеринга → Layout (reflow) → Paint → Composite**.

**Reflow** — пересчёт геометрии (дорого). **Repaint** — перерисовка пикселей. **Composite** — слои GPU.

Изменения **`transform`/`opacity`** часто остаются на композитинг-слое; изменение размеров/позиции в потоке может вызвать layout.

**Render-blocking:** синхронный CSS в head — блокирует первый рендер пока не загрузится (упрощённо). **Parser-blocking:** синхронный JS без defer — блокирует парсинг HTML.

---

## Garbage Collection и утечки

**Mark-and-sweep:** GC помечает достижимые объекты из корней (глобал, стек вызовов, closures).

**Утечки:** забытые слушатели, замыкания держащие большие объекты, таймеры, кеш без eviction, ссылки на удалённые DOM-узлы из JS, циклы со старыми WeakRef не нужны — но сильные ссылки да.

Инструменты: Memory tab в DevTools, heap snapshots.

---

## Proxy и Reflect

**Proxy** перехватывает `get`, `set`, `has`, `ownKeys` и т.д. Используется для реактивности, логирования, валидации.

**Reflect** — безопасное выполнение тех же операций по умолчанию внутри traps.

---

## Symbol (углублённо)

Помимо **Symbol.iterator**:  
**Symbol.toPrimitive** — как объект приводится к примитиву; **Symbol.hasInstance** — `instanceof`; **Symbol.asyncIterator** — async iteration.

---

## WeakRef и FinalizationRegistry

**WeakRef** — слабая ссылка на объект (не удерживает от GC). **FinalizationRegistry** — колбэк когда объект собран (ненадёжные тайминги; не для критичной логики).

---

## Web APIs: Observers

- **Intersection Observer** — видимость, lazy load, бесконечный скролл.
- **Resize Observer** — размер элемента без polling.
- **Mutation Observer** — изменения DOM (тяжёло; по возможности избегать).
- **Performance Observer** — Long Tasks, navigation timing, Web Vitals на клиенте.

---

## Web Workers

Отдельный поток без доступа к DOM. Обмен через **`postMessage`** (клонирование или **Transferable** для ArrayBuffer).

**SharedWorker** редок; чаще один Dedicated Worker для тяжёлых вычислений, парсинга, WASM.

---

## WebSocket

Дуплекс поверх TCP; события `open`, `message`, `error`, `close`. Для **reconnect**: экспоненциальный backoff, heartbeat/ping, идемпотентность после разрыва.

---

## Server-Sent Events (SSE)

Односторонний поток сервер → клиент через HTTP; **`EventSource`** в браузере; авто-reconnect; проще чем WS если не нужен клиент→сервер в том же канале.

---

## IndexedDB

Ключ-значение с индексами, асинхронный API (современно **`idb`** обёртки). Транзакции `readonly`/`readwrite`, версии схемы `onupgradeneeded`.

Для больших офлайн-кэшей; сложнее чем LocalStorage.

---

## LocalStorage / SessionStorage

Синхронный API, блокирует поток на больших данных; только строки; лимит ~5MB; Same-origin. **`storage`** event между вкладками одного origin (LocalStorage).

---

## Clipboard API

`navigator.clipboard.writeText()` — только в **secure context** и часто после жеста пользователя; Permissions Policy может ограничить.

---

## History API

`history.pushState` / `replaceState` + событие `popstate` — основа SPA-роутинга; не забывай синхронизировать состояние с экраном и доступностью.

---

## File API и Blob

`FileReader`, `URL.createObjectURL(blob)` — превью; не забывай **`revokeObjectURL`**.

---

## AbortController

```js
const ac = new AbortController();
fetch(url, { signal: ac.signal });
ac.abort(); // отмена
```

Комбинируй с **`AbortSignal.timeout(ms)`** (современные браузеры) или гонкой нескольких сигналов через **`AbortSignal.any()`**.

---

## Debounce и Throttle

**Debounce** — вызов после паузы (поиск при вводе). **Throttle** — не чаще N мс (scroll).

Реализация через таймеры + trailing/leading опции.

---

## Каррирование и частичное применение

Каррирование: `add(a)(b)`. Частичное применение: `bind` или обёртки. На фронте — конфигурируемые хэндлеры.

---

## Иммутабельность

Неизменяемые структуры упрощают сравнение и отладку; **Immer** даёт мутабельный синтаксис с иммутабельным результатом; **`structuredClone`** для глубокого копирования без циклов DOME.

---

## Optional chaining и nullish coalescing

**`?.`** коротко обрывает цепочку; не заменяет проверку на `''` или `0`.

**`??`** только для `null`/`undefined`; отличие от `||`: `0 ?? 10` → `0`.

---

## Intl API

Форматирование чисел, дат, относительных дат (`Intl.RelativeTimeFormat`), сортировка строк по локали (`Collator`), множественное число (`PluralRules`). Важно для i18n без тяжёлых библиотек для базовых кейсов.
