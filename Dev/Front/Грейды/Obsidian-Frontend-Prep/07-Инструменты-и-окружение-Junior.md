# Инструменты и окружение — Junior

## Git: что обязательно уметь руками?

Базовые команды:
`init`, `clone`, `add`, `commit`, `push`, `pull`, `branch`, `switch/checkout`, `merge`, `log`, `diff`, `stash`.

Junior должен уметь:
- работать в feature-ветке
- оформлять понятные коммиты
- открывать MR/PR без лишнего мусора в diff

## Merge conflicts: как действовать правильно?

1. понять, какие изменения конфликтуют
2. выбрать или объединить нужные части
3. удалить конфликтные маркеры
4. прогнать проект/тесты
5. закоммитить результат

Главное — не «закрыть конфликт любой ценой», а сохранить корректную логику.

## `.gitignore`: зачем он нужен?

Файл исключает из репозитория локальные/временные артефакты: `node_modules`, сборку, кэши, локальные `.env`.  
Это делает репозиторий чище и снижает риск утечки локальных данных.

## npm/yarn/pnpm: что ожидать на Junior?

Нужно понимать:
- установку/удаление пакетов
- scripts из `package.json`
- роль lock-файла
- основы semver (`major.minor.patch`, диапазоны `^`/`~`)

## ESLint и Prettier

- ESLint помогает ловить потенциальные ошибки и анти-паттерны
- Prettier отвечает за единообразное форматирование

Вместе это уменьшает шум в code review.

## Chrome DevTools: базовый рабочий набор

- Elements — инспекция DOM и CSS
- Console — логи и выполнение JS
- Network — запросы, статусы, время
- Application — localStorage/sessionStorage/cookies

## IDE и продуктивность

Junior полезно уверенно владеть:
- поиском по проекту
- рефакторингами (rename/extract)
- форматированием и линтингом
- горячими клавишами навигации

## Командная строка

Базовые команды:
`cd`, `ls`, `mkdir`, `rm`, `cp`, `mv`, `chmod`, базовый `ssh`.

Цель — уверенно запускать проект, скрипты и простые служебные операции.

## Что такое `node_modules`?

`node_modules` — директория установленных зависимостей проекта.  
Обычно не коммитится, потому что восстанавливается через lock-файл и пакетный менеджер.
