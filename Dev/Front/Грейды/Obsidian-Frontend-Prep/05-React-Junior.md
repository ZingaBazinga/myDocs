# React — Junior

## Что такое JSX и как его объяснить?

JSX — синтаксис, который позволяет описывать UI в JavaScript.  
В JSX можно вставлять выражения через `{...}`, писать условия и рендерить списки.

Классические кейсы:
- условный рендер через тернарный оператор или `&&`
- список через `array.map(...)`
- у элементов списка должен быть стабильный `key` (обычно `id`)

## Функциональные компоненты

Функциональный компонент — функция, которая принимает `props` и возвращает JSX.  
Сейчас это основной стиль React-разработки.

## Базовые хуки: что важно знать

- `useState` — локальное состояние
- `useEffect` — сайд-эффекты (запросы, подписки, синхронизация)
- `useContext` — доступ к значениям контекста
- `useRef` — ссылка на DOM или мутабельное значение без ререндера
- `useMemo`/`useCallback` — базовая оптимизация

На Junior важно понимать не все edge-cases, а корректные базовые сценарии.

## Правила хуков

Хуки вызываются:
1. только на верхнем уровне компонента/кастомного хука
2. только внутри React-функций

Причина: React опирается на неизменный порядок вызовов хуков между рендерами.

## Props и `children`

`props` — входные данные компонента.  
`children` — вложенный контент для композиции.

Junior должен уверенно делать декомпозицию интерфейса на переиспользуемые компоненты и передавать в них данные через props.

## Что такое lifting state up?

Если одно состояние нужно нескольким компонентам, его поднимают в ближайшего общего родителя и прокидывают вниз через props.  
Это базовый паттерн синхронизации UI без лишних глобальных сторов.

## Формы в React

- Управляемые компоненты: значение хранится в `state` и обновляется через `onChange`
- Неуправляемые: значение хранится в DOM, доступ через `ref`

На практике чаще применяют управляемые формы.

## События в React

React использует SyntheticEvent — кроссбраузерную обертку над нативными событиями.  
Основные обработчики: `onClick`, `onChange`, `onSubmit`, `onBlur`, `onFocus`.

## Базовый роутинг (TanStack Router)

Нужно понимать:
- `Route` для описания маршрута
- `Link` для клиентской навигации
- `useNavigate` для программного перехода
- `useParams` для чтения параметров URL
