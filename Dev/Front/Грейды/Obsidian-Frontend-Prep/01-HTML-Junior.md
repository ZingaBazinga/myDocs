# HTML — Junior

## Что такое `<!DOCTYPE html>` и зачем он нужен?

`<!DOCTYPE html>` сообщает браузеру, что документ надо рендерить в standards mode.  
Если doctype нет, браузер может перейти в quirks mode: меняется поведение CSS, появляются неожиданные отличия между браузерами. На практике doctype должен быть в каждой HTML-странице.

## В чем смысл семантических тегов?

Семантические теги описывают назначение блока:
- `header`, `nav`, `main`, `footer` — структура страницы
- `section`, `article`, `aside` — смысловые части контента
- `figure`, `figcaption`, `time`, `mark`, `details`, `summary` — контентные роли

Польза: лучше доступность для скринридеров, проще SEO и понятнее поддержка кода.

## Что важно знать про формы?

Базовый набор:
- `input` разных типов (`text`, `email`, `password`, `number`, `date`, `file`, `checkbox`, `radio`, `range`, `color`)
- `select`, `textarea`
- `label`, `fieldset`, `legend`

Ключевая практика: всегда связывай `label` с полем через `for` и `id` (или через вложенность), чтобы клик по подписи фокусировал поле.

## Как работает встроенная валидация?

Атрибуты `required`, `pattern`, `min`, `max`, `minlength`, `maxlength`, `step` позволяют браузеру проверять данные до отправки.  
Это улучшает UX, но не заменяет серверную валидацию.

## Какие meta-теги обязательны для Junior?

- `charset="UTF-8"` — корректная кодировка
- `viewport` — адаптивность на мобильных
- `description` — описание для поисковых сниппетов
- Open Graph (`og:*`) — корректное превью ссылок в мессенджерах/соцсетях

## Блочные и строчные элементы: что это на практике?

- Блочные (`div`, `section`, `p`) обычно занимают всю строку
- Строчные (`span`, `a`, `strong`) располагаются внутри текста

Это базовое поведение, которое можно изменить через `display`, но понимать его нужно для диагностики верстки.

## Что такое `data-*` и когда использовать?

`data-*` хранит служебные данные прямо в DOM, например `data-id="123"`.  
Доступ в JS: `element.dataset.id`.

Подходит для небольших связок UI и логики (атрибуты для селекторов, тестов, аналитики).

## Базовая доступность в HTML

- у осмысленных изображений есть `alt`
- корректная иерархия заголовков `h1` -> `h2` -> `h3`
- все интерактивные элементы достижимы с клавиатуры
- `aria-label` применяется там, где нет видимой подписи

## Как правильно встраивать медиа?

- `img` для изображений
- `video`/`audio` для мультимедиа
- `picture` + `source` для разных форматов и брейкпоинтов
- `srcset`/`sizes` для адаптивной загрузки изображений

Это напрямую влияет на производительность и качество отображения.

## `div` или семантический тег?

`div` — нейтральный контейнер без смысла.  
Если блок имеет роль (навигация, основной контент, статья), выбирай семантический тег. Это снижает технический долг и улучшает доступность.
