# Junior — карточки Q/A

Использование: закрой ответ рукой/скроллом, сначала проговори вслух, потом сверяйся.

---

## HTML

**Q:** Зачем нужен `<!DOCTYPE html>`?  
**A:** Включает standards mode; без него возможен quirks mode с непредсказуемой версткой.

**Q:** Почему важна семантическая разметка?  
**A:** Улучшает доступность, SEO и читаемость структуры страницы.

**Q:** Что обязательно в форме кроме `input`?  
**A:** `label`, а также при необходимости `fieldset/legend`, `select`, `textarea`.

**Q:** Назови базовые атрибуты нативной валидации.  
**A:** `required`, `pattern`, `min`, `max`, `minlength`, `maxlength`, `step`.

**Q:** Какие meta-теги must-have?  
**A:** `charset`, `viewport`, `description`, часто `og:*`.

**Q:** Когда применять `data-*`?  
**A:** Для служебных данных в DOM, доступ через `element.dataset`.

**Q:** Чем опасен `div` везде?  
**A:** Теряется смысл структуры и ухудшается доступность; лучше семантические теги.

## CSS

**Q:** Что входит в box model?  
**A:** `content`, `padding`, `border`, `margin`.

**Q:** Почему часто ставят `box-sizing: border-box`?  
**A:** Проще считать размеры: padding и border включены в ширину/высоту.

**Q:** Разница `absolute` и `fixed`?  
**A:** `absolute` — относительно предка, `fixed` — относительно viewport.

**Q:** Когда выбрать Flexbox, а когда Grid?  
**A:** Flexbox для 1D-раскладки, Grid для 2D (строки и колонки).

**Q:** Почему «не применяется стиль»?  
**A:** Обычно из-за специфичности, каскада, порядка правил или наследования.

**Q:** Что делает `:focus-visible`?  
**A:** Показывает фокус в сценариях клавиатурной навигации.

**Q:** Что такое mobile-first?  
**A:** Базовые стили для мобильных, расширение через `@media (min-width: ...)`.

## JavaScript

**Q:** Почему `===` предпочтительнее `==`?  
**A:** Не делает неявного приведения типов, меньше неожиданных сравнений.

**Q:** Что такое замыкание?  
**A:** Функция, которая помнит переменные внешнего лексического окружения.

**Q:** Как работает `this` в стрелочной функции?  
**A:** Не имеет собственного `this`, берет его из внешнего контекста.

**Q:** Что делает `Promise.all`?  
**A:** Ждет все промисы; падает на первой ошибке.

**Q:** Что такое event loop в одном предложении?  
**A:** Сначала синхронный код, потом микрозадачи, потом макрозадачи.

**Q:** Когда лучше `textContent`, а не `innerHTML`?  
**A:** Для пользовательского текста, чтобы избежать XSS.

**Q:** Что такое делегирование событий?  
**A:** Один обработчик на родителе обслуживает события дочерних элементов.

**Q:** Когда использовать `structuredClone`?  
**A:** Когда нужно глубокое копирование данных без ручной рекурсии.

## Работа с сетью

**Q:** Что означают классы HTTP-кодов `2xx/4xx/5xx`?  
**A:** Успех / ошибка клиента / ошибка сервера.

**Q:** Бросает ли `fetch` исключение на 404?  
**A:** Нет, нужно проверять `response.ok`; исключение — обычно только network error.

**Q:** Что такое REST в базовом виде?  
**A:** Ресурсы по endpoint и CRUD-операции через HTTP-методы.

**Q:** Что такое CORS?  
**A:** Браузерная политика доступа к cross-origin ответам.

**Q:** Зачем нужен HTTPS?  
**A:** Шифрует трафик и подтверждает подлинность сервера через TLS.

**Q:** Что дают атрибуты cookie `HttpOnly`, `Secure`, `SameSite`?  
**A:** Защищают от чтения JS, ограничивают HTTPS-only и cross-site отправку.

## React

**Q:** Зачем `key` в списках React?  
**A:** Для корректного reconciliation и стабильного обновления элементов.

**Q:** Что делает `useState`?  
**A:** Хранит локальное состояние компонента и триггерит ререндер при обновлении.

**Q:** Для чего `useEffect`?  
**A:** Для сайд-эффектов: запросы, подписки, синхронизация с внешним миром.

**Q:** Назови 2 правила хуков.  
**A:** Вызывать только на верхнем уровне и только в React-функциях.

**Q:** Что такое lifting state up?  
**A:** Подъем общего состояния в ближайший общий родитель.

**Q:** Разница управляемой и неуправляемой формы?  
**A:** В управляемой источник истины — React state, в неуправляемой — DOM.

## TypeScript

**Q:** Разница между `any` и `unknown`?  
**A:** `any` отключает проверки, `unknown` требует сужения перед использованием.

**Q:** Когда использовать union `|`?  
**A:** Когда значение может быть одним из нескольких типов.

**Q:** Когда intersection `&`?  
**A:** Когда объект должен удовлетворять сразу нескольким типам.

**Q:** Что такое type assertion?  
**A:** Явное утверждение типа через `as`, без runtime-проверки.

**Q:** Что дают `keyof` и `typeof`?  
**A:** `keyof` — ключи типа, `typeof` — тип из значения.

## Инструменты

**Q:** Минимальный git-набор Junior?  
**A:** `add`, `commit`, `push`, `pull`, `branch`, `switch`, `merge`, `log`, `diff`.

**Q:** Что делать после решения merge-conflict?  
**A:** Проверить сборку/тесты и только потом коммитить результат.

**Q:** Зачем lock-файл (`package-lock`/`yarn.lock`)?  
**A:** Фиксирует точные версии зависимостей для воспроизводимых установок.

**Q:** Разница ESLint и Prettier?  
**A:** ESLint про качество/ошибки, Prettier про форматирование.

**Q:** Какие вкладки DevTools ты используешь ежедневно?  
**A:** Elements, Console, Network, Application.

## Тестирование и soft skills

**Q:** Какие 3 уровня тестов базово знать?  
**A:** Unit, integration, E2E.

**Q:** Зачем моки в тестах?  
**A:** Изолировать тест от внешних зависимостей и сделать его стабильным.

**Q:** В чем идея Testing Library?  
**A:** Тестировать поведение пользователя, а не внутреннюю реализацию.

**Q:** Как кратко показывать soft skills на ревью?  
**A:** Формулой: контекст -> действие -> результат.

**Q:** Что важно по коммуникации Junior?  
**A:** Ранние сигналы о блокерах, уточнение требований, прозрачный статус.

1. Пройди все карточки за 20-30 минут.
